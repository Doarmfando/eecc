# Decisiones de arquitectura

Los Architecture Decision Records (ADR) explican decisiones duraderas y sus consecuencias. No se reescriben para ocultar cambios: se marcan como reemplazados por un ADR posterior.

## Estados

- Propuesta
- Aceptada
- Rechazada
- Reemplazada por ADR-NNNN

## Plantilla

```markdown
# ADR-NNNN: Título

- Estado: Propuesta
- Fecha: YYYY-MM-DD

## Contexto
## Decisión
## Alternativas consideradas
## Consecuencias
## Criterio de revisión
```
